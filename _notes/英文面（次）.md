### 0:40—1:20

**Professor: What is value-hijacking? Please explain it simply.**

> Value-hijacking means that an attacker makes poisoned data look valuable to a data selector. The selector is designed to keep useful samples, but it cannot directly know whether a sample is safe. If the poisoned data copies the signals that the selector prefers, the selector may choose more of it. In this way, a filter becomes an amplifier.

### 1:20—2:00

**Professor: Why can the selector be misled?**

> A selector usually uses a value score as a simple sign of data quality. It may prefer data that looks useful, difficult, or informative. However, a high value score does not always mean that the sample is safe. An attacker can copy these surface features. When the selector keeps only the top samples, the poison rate may become higher.

### 2:00—2:40

**Professor: Why is your method gradient-free?**

> Our method does not calculate, read, or send gradients back through the target system. It generates candidate responses and ranks them with limited selection feedback. The target selector may use gradients inside its own method, but the attacker cannot access them. We must separate what the selector does inside from what information the attacker can use.

### 2:40—3:20

**Professor: What does the 5.18-times result mean?**

> It is a poison enrichment result under one representative setting. After selection, the poison concentration became 5.18 times its original level in the candidate pool. Under the same setting, the strongest baseline reached 1.85 times. It does not mean that every model has the same result. The number is linked to a specific model, selector, and selection ratio.

### 3:20—4:05

**Professor: What is the biggest limitation of your work?**

> One limitation is that we tested only a limited number of model families and data selectors. Another limitation is that our main setting still needs some selector feedback. We tested coarse feedback, but a fully closed system may be harder to attack. Also, high poison enrichment does not always cause the same level of model damage. These points need more study.

### 4:05—4:50

**Professor: What do you want to study next?**

> I want to move from showing the risk to building practical defenses. One idea is to design a selector that considers both data value and security risk. I also want to study attacks and defenses with very little feedback. In the long term, I hope to improve the safety of the full fine-tuning process, from data source and selection to training and model release.

## 五、Value-Hijacking主论文

### 20. Please explain your research in simple words.

> Large language models are often fine-tuned with only a small part of a very large data pool. A data selector chooses the samples that look most useful. We found that an attacker can create poisoned samples that look valuable to this selector. The selector may then choose more poisoned samples. Our work studies this risk and proposes an attack method to test how serious the problem can be.

**中文意思：** 选择器从大量数据选少量高价值数据，但攻击者能让恶意样本看起来很有价值。

**记忆关键词：** large pool → selector → useful data → poisoned data → security risk。

---

### 21. What is a data selector?

> A data selector is a method that gives each training sample a value score or a selection priority. It then chooses a small part of the data for model training. The purpose is usually to reduce cost and keep useful samples. However, the selector does not directly know whether a sample is safe. If its value signal can be copied or misled, it may make a wrong choice.

**中文意思：** 选择器根据价值分数选数据，目标是省成本和保留有用样本，但高价值不等于安全。

**记忆关键词：** value score → small part → lower cost → useful is not always safe。

---

### 22. What is value-hijacking?

> Value-hijacking means that an attacker copies or imitates the signals that a data selector considers valuable. The poisoned sample still keeps its harmful goal, but it looks useful to the selector. As a result, the normal selection process is used by the attacker. The selector becomes an amplifier of poisoned data instead of a filter. That is the main failure mode studied in our work.

**中文意思：** 恶意样本模仿高价值特征，劫持选择器的价值判断，让选择器变成放大器。

**记忆关键词：** imitate value → keep harmful goal → selector misled → amplifier。

---

### 23. How is value-hijacking different from normal data poisoning and prompt injection?

> Normal data poisoning mainly studies how harmful training samples change a model after training. Value-hijacking focuses on an earlier step: which samples are selected before fine-tuning. It explains why the poison ratio may become higher during selection. Prompt injection is different because it usually attacks a model through an input prompt during use. The three problems happen at different stages of the AI pipeline.

**中文意思：** 普通投毒关注训练后影响；价值劫持关注训练前的数据选择；提示注入通常发生在推理使用阶段。

**记忆关键词：** before selection → after training → during use → different stages。

---

### 24. Why can a selector amplify poisoned samples?

> A selector normally uses a simple signal to estimate data value. For example, it may prefer samples that look informative, difficult, or helpful for model learning. An attacker can design poisoned samples that show the same surface signals. Because the selector only sees its value score, it may rank these samples very high. When only the top samples are kept, their poison ratio becomes higher.

**中文意思：** 选择器依赖代理指标，攻击样本模仿该指标，在Top-k筛选后投毒比例升高。

**记忆关键词：** value signal → imitate → high rank → Top-k → higher poison rate。

---

### 25. What is your threat model?【需本人确认8：攻击预算与反馈接口】

> In our main setting, the attacker can place crafted samples in the candidate data pool and receive limited information about how the selector values them. The attacker cannot change the selector, the training program, or the model parameters. The attacker also has no direct gradient access. The exact attack budget and feedback level must follow the settings defined in our paper.

**中文意思：** 攻击者能放入恶意候选样本并获得有限反馈，但不能改系统、模型参数，也拿不到梯度。

**记忆关键词：** add samples → limited feedback → cannot change system → no gradients。

---

### 26. What is AMRS?

> AMRS stands for Anchor-Mimicry Response Synthesis. It has three simple steps. First, it finds examples that receive high value from the selector and uses them as anchors. Second, it generates several poisoned responses that imitate useful features of these anchors. Third, it ranks the candidates and keeps those that score well while preserving the attack goal. It is a generate-and-rank method.

**中文意思：** 找高价值锚点 → 模仿其特征生成多个恶意候选 → 排序并保留兼顾攻击效果和高分的候选。

**记忆关键词：** anchors → imitate → generate → rank → keep attack goal。

---

### 27. Why do you call AMRS training-free and gradient-free?

> AMRS does not train an additional attack model, and it does not calculate or read gradients from the target system. It only generates candidate responses and uses available selection feedback to rank them. A target selector may use gradients inside its own algorithm, but that does not mean the attacker can access those gradients. We must separate the internal design of the selector from the attacker's ability.

**中文意思：** 目标选择器内部可能用梯度，但攻击方法本身不训练、不读取梯度，两者不矛盾。

**记忆关键词：** no attack training → no gradient access → selector internal method → separate abilities。

---

### 28. Is your attack black-box or gray-box?

> In the main setting, the attacker receives some form of selector feedback, so I would describe it as a limited-feedback or gray-box setting, rather than a fully closed black box. We also tested coarse feedback to reduce this assumption. If there is no score, rank, or selection feedback at all, the current method becomes weaker. A fully feedback-free attack is an important future direction.

**中文意思：** 主设定更接近有限反馈灰盒，不应硬说完全黑盒；完全无反馈是未来工作。

**记忆关键词：** limited feedback → gray-box → coarse feedback → no feedback limitation。

---

### 29. What does 5.18 times mean?

> It is a poison enrichment result under one representative test setting. In simple words, after selection, the poison concentration was 5.18 times its original level in the candidate pool. Under the same setting, the strongest baseline reached 1.85 times. This number does not mean that every model or every selector has a 5.18-times result. It is tied to a specific experimental setting.

**中文意思：** 5.18倍是特定设置下筛选后的投毒富集度，不是所有模型的统一结果。

**记忆关键词：** selected poison rate → original rate → 5.18 → baseline 1.85 → specific setting。

---

**记忆关键词：** small selected set → practical cost → stable test → actual ratios only。

**记忆关键词：** selection metric → downstream damage → instruction following → MMLU below 1% → targeted effect。

### 33. What is the main novelty of your work?

> I think the main novelty is the failure mode itself. Previous work often treats data selection as a way to improve quality or reduce cost. We show that the value signal of a selector can become a new attack surface. We also design AMRS to test this problem without extra training or gradient access, and evaluate it across two model families and four data selectors.

**中文意思：** 核心创新是发现“选择器价值信号本身就是攻击面”，并提出低门槛攻击验证。

**记忆关键词：** new failure mode → selector as attack surface → AMRS → two models → four selectors。

### 34. What is the biggest limitation of your work?

> One limitation is that we tested only a limited number of model families and data selectors. Another limitation is that the main threat model still needs some form of selector feedback. We tested coarse feedback, but a fully closed system may be harder to attack. Also, high poison enrichment does not always lead to the same level of downstream damage. More models, domains, and defenses should be studied.

**中文意思：** 模型和选择器覆盖有限、依赖一定反馈、富集度不一定等比例转化为损害。

**记忆关键词：** limited models → feedback assumption → enrichment versus damage → more tests。

### 35. How can we defend against value-hijacking?

> I think defense should use more than one signal. First, a selector should consider safety as well as utility. Second, the system can check unusual similarity, repeated response patterns, and sudden changes in the selected data. Third, random selection and diversity rules may make the selector harder to predict. Finally, a small part of high-risk data should receive human review before fine-tuning.

**中文意思：** 联合价值和安全评分、异常检测、多样性与随机化、人工审计。

**记忆关键词：** utility plus safety → anomaly check → diversity → randomization → human review。

### 46. What is the difference between machine learning and deep learning?

> Machine learning is a broad field in which a computer learns patterns from data. Traditional machine learning often needs people to design useful features. Deep learning is one part of machine learning. It uses neural networks with many layers to learn features automatically. Deep learning is powerful for large and complex data, but it usually needs more data, computing power, and careful training.

**中文意思：** 深度学习是机器学习的一部分，能自动学习特征，但需要更多数据、算力和训练控制。

### 47. What is a Transformer?

> A Transformer is a neural network structure that mainly uses attention. Attention allows each token to look at other tokens and decide which information is important. Unlike an RNN, a Transformer can process many tokens in parallel during training. This makes it suitable for large-scale language models. Its main parts include attention, feed-forward layers, normalization, and position information.

**中文意思：** Transformer以注意力为核心，能并行处理序列，是大语言模型的基础结构。

**记忆关键词：** attention → tokens → parallel → language model → feed-forward。

---

### 48. What is self-attention?

> Self-attention allows every token in a sequence to collect information from other tokens in the same sequence. Each token creates a query, a key, and a value. The query and keys are used to calculate attention scores. These scores decide how much information should be taken from each value. In simple words, the model learns which words should pay attention to which other words.

**中文意思：** 每个词通过Q、K计算相关性，再对V加权，从其他词中获取信息。

**记忆关键词：** query → key → score → value → collect information。

---

### 49. What is overfitting, and how can we reduce it?

> Overfitting means that a model performs well on training data but poorly on new data. It learns details or noise that do not generalize. We can reduce it by using more data, data augmentation, regularization, dropout, early stopping, or a smaller model. We should also keep training, validation, and test data separate and use the validation set to choose model settings.

**中文意思：** 训练集好、未见数据差就是过拟合；解决方法包括更多数据、正则化、Dropout、早停和规范划分。

**记忆关键词：** training good → new data poor → noise → regularization → separate sets。

---

### 50. What is the difference between training, validation, and test sets?

> The training set is used to update model parameters. The validation set is used to choose model settings, compare methods, and decide when to stop training. The test set is used only for the final evaluation. If we repeatedly use test results to change the model, information from the test set leaks into development, and the final result is no longer reliable.

**中文意思：** 训练集更新参数，验证集调参，测试集只做最终评价；反复看测试集会造成泄漏。

**记忆关键词：** train parameters → validation choices → test final → no leakage。
