# 计算机网络 · 保研面试口语手册【补充篇】

> 这份是对主手册的补漏。主手册偏"互联网工程向"（TCP/HTTP/HTTPS）， 这份补的是"408 教材向"——保研老师手里常拿着谢希仁或王道提问， 这些题秋招基本不问，但保研面试出现频率不低。 两份配合使用，覆盖度就基本完整了。

## 补充 1：概述与性能指标

### Q1 三种交换方式的区别？★★★（保研高频，秋招不问）

**【通俗讲解】**

- 电路交换：打电话。先拨号建立一条专线，全程独占，说不说话线都占着。
- 报文交换：整封信原封不动地在每个中转站存下来再转发，信太大就堵着后面的。
- 分组交换：把信拆成小页码，每页独立传，中转站收一页转一页，流水线并行。

**【面试怎么答】** "电路交换分三个阶段：建立连接、数据传输、释放连接。它独占物理通路，时延小且稳定，适合实时通信，但线路利用率低，因为不发数据时线路也被占着。

报文交换采用存储转发，把整个报文作为一个整体传输，不需要预先建立连接，线路利用率提高了。但缺点是报文长度不受限制，中间结点需要很大的缓存，而且必须完整收下整个报文才能转发，转发时延很大。

分组交换也是存储转发，但限制了每次传输的数据块大小，把大报文切成若干分组，每个分组加上首部独立传输。好处是各结点可以流水线式并行转发，时延显著降低，缓存需求也小。代价是每个分组都要带首部，有额外开销，而且可能出现失序、丢失、重复。

现在的互联网用的就是分组交换。"

### Q2 虚电路和数据报有什么区别？★★★

**【面试怎么答】** "这是分组交换的两种服务方式，区别在网络层是否面向连接。

虚电路是面向连接的：传数据前先建立一条逻辑通路，所有分组沿同一路径按序传输，每个分组只需要携带虚电路号而不用完整地址，能保证顺序，可靠性较好。缺点是灵活性差——一旦路径上某个结点故障，所有经过它的虚电路全部失效。

数据报是无连接的：每个分组独立选路，携带完整目的地址，可能走不同路径，到达顺序可能乱。好处是灵活，某个结点故障时其他分组可以绕路，健壮性强。

互联网的 IP 层选择了数据报方式，这是一个重要的设计哲学：把复杂度和可靠性保障放到端系统的传输层去做，网络核心保持简单，也就是端到端原则。这样网络更容易扩展，也能支撑各种异构的上层应用。"

### Q3 点到点通信和端到端通信有什么区别？★★

**【面试怎么答】** "点到点是相邻结点之间的通信，由物理层、数据链路层和网络层共同提供，管的是机器到机器把数据送过去，不涉及具体是哪个进程，也不保证整体可靠。

端到端是传输层提供的，建立在一段段点到点通信的基础上，实现的是源主机上某个进程和目的主机上某个进程之间的通信。这里的'端'指的是端口，端口号标识了应用层的不同进程。

一句话：点到点解决机器怎么把数据传到下一跳，端到端解决两个进程之间怎么完整可靠地对话。"

### Q4 网络的主要性能指标有哪些？时延由哪几部分组成？★★

**【面试怎么答】** "主要指标有速率、带宽、吞吐量、时延、时延带宽积、往返时间 RTT 和信道利用率。

其中时延最容易被追问，它由四部分组成：

发送时延，是把数据全部推上链路所需的时间，等于数据长度除以发送速率，取决于带宽和数据量。 传播时延，是信号在链路上跑完全程的时间，等于距离除以电磁波传播速度，只取决于物理距离，和带宽无关。 处理时延，是结点分析首部、查表、差错检验的时间。 排队时延，是分组在路由器输入输出队列里等待的时间，网络越拥塞越长，波动最大。

这里最容易混的是发送时延和传播时延：提高带宽只能减小发送时延，减不了传播时延。所以从北京到纽约的延迟有一个物理下限，光速摆在那里，这也是 CDN 要把内容放到离用户近的地方的原因。

时延带宽积等于传播时延乘以带宽，物理意义是链路上'正在飞行'的比特数，可以理解为这条链路这根管子能容纳多少数据。"

### Q5 计算机网络按覆盖范围怎么分类？★

**【面试怎么答】** "按覆盖范围分为广域网 WAN、城域网 MAN、局域网 LAN 和个人区域网 PAN。按使用者分公用网和专用网。按拓扑结构分总线型、星型、环型、网状。按交换方式分电路交换、报文交换和分组交换网络。"

## 补充 2：物理层（补信道复用）

### Q6 为什么要信道复用？有哪些复用技术？★★

**【通俗讲解】** 一条昂贵的高速公路，只给一辆车走太浪费。频分是把路划成多条车道同时跑（分频不分时）；时分是所有车轮流用整条路（分时不分频）；波分是光纤版的频分；码分是所有人同时说话但用不同的语言，各自只听得懂自己那一种。

**【面试怎么答】** "复用的目的是让多个用户共享一条昂贵的信道，提高利用率。主要有四种：

频分复用 FDM：所有用户同时通信，但各占不同的频段，分频不分时。 时分复用 TDM：所有用户占用相同频带，但轮流占用不同的时间片，分时不分频。它的问题是某个用户没数据发时时间片也空着浪费了，所以有改进的统计时分复用，按需动态分配时隙，利用率更高。 波分复用 WDM：本质上就是光纤上的频分复用，用不同波长的光承载不同信道。 码分复用 CDM：每个用户分配一个唯一的正交码片序列，所有用户可以同时同频发送，接收方用对应的码片做相关运算就能分离出自己的信号。因为码片序列正交，互相不干扰。"

### Q7 信道的极限速率受什么限制？★

**【面试怎么答】** "两个定理。奈奎斯特定理针对理想无噪声信道，说明带宽限制了码元传输速率的上限；香农定理针对有噪声信道，信道极限容量由带宽和信噪比共同决定。

结论是提高带宽和提高信噪比都能提升速率上限，但香农公式里信噪比是取对数的，所以继续提高信噪比的收益会递减。另外提高每个码元携带的比特数也能提升数据率，代价是抗噪声能力下降。"

## 补充 3：数据链路层（补差错编码与设备）

### Q8 差错控制有哪几种编码？海明码和 CRC 的区别？★★

**【面试怎么答】** "分检错编码和纠错编码两类。

检错编码只发现错误不修复，出错就丢弃重传。包括奇偶校验码，只能检出奇数位错误，能力很弱；以及 CRC 循环冗余校验，用生成多项式做模二除法，把余数作为冗余码，检错能力强、硬件实现简单，是链路层的主流。

纠错编码能定位并修复错误，代表是海明码。它的思路是插入若干校验位，让每个数据位被多个校验位交叉监督，出错时几个校验位同时异常，异常的组合就能指出错在第几位。海明码能纠正一位错误、检出两位错误。校验位数 r 和数据位数 k 要满足 2 的 r 次方大于等于 k 加 r 加 1。

两者的取舍是：纠错开销大，适合重传代价很高的场合，比如卫星通信、存储介质；而在链路层，重传很便宜，所以用检错加重传更划算。这也是链路层普遍用 CRC 而不用海明码的原因。"

### Q9 链路层的流量控制和传输层的流量控制有什么区别？★★（好追问点）

**【面试怎么答】** "作用范围不同。链路层的流量控制是点到点的，控制的是相邻两个结点之间；传输层的是端到端的，控制的是源主机和目的主机之间。

手段也不同。链路层的做法是接收方收不过来就不回确认帧，发送方收不到确认就停下；传输层是接收方主动在报文段里通告一个窗口值，明确告诉发送方还能发多少。传输层的方式更精细。"

### Q10 网卡工作在哪一层？MAC 地址和 IP 地址为什么都需要？★★★

**【通俗讲解】** IP 地址像收件地址，是逻辑的、会变的，用来在全球范围内规划路线；MAC 地址像身份证号，是烧在硬件里的、全球唯一且不变，用来在最后一段路上精确找到那台机器。快递单上写着最终地址，但每一段中转都是靠具体的车牌和站点完成的。

**【面试怎么答】** "网卡横跨物理层和数据链路层，它负责比特的收发和 MAC 帧的封装解封装。

MAC 地址是链路层地址，固化在网卡上，全球唯一，用于同一局域网内标识具体设备。IP 地址是网络层地址，是逻辑地址，带有网络号信息，可以按网络拓扑分配和聚合。

两者都需要的原因是：IP 地址是分层的，路由器可以根据网络前缀做聚合寻址，路由表才不至于爆炸，这是全球路由的基础；但真正在一条链路上把帧交给某台具体设备，靠的是 MAC 地址。所以数据传输过程中，IP 首部里的源和目的 IP 全程不变，而每经过一跳，MAC 帧的源和目的 MAC 都会被改写成本段链路的两端。ARP 就是负责在每一跳把下一跳 IP 翻译成 MAC 的。"

### Q11 网桥的自学习是怎么回事？VLAN 有什么用？★

**【面试怎么答】** "交换机刚上电时转发表是空的，它采用自学习：收到一个帧时，把帧的源 MAC 和进入的端口号记录进转发表，这样就知道了那个 MAC 挂在哪个端口。转发时查表，查到就单播到对应端口，查不到就向除来源端口外的所有端口洪泛。表项有过期时间，以适应设备移动。

VLAN 是虚拟局域网，用来在一台或多台交换机上划分多个逻辑广播域。因为交换机不隔离广播域，一个大的交换网络里广播风暴风险高、安全性差，VLAN 通过在帧里加标签把不同 VLAN 的流量隔离开，不同 VLAN 之间通信必须经过路由器或三层交换机。"

### Q12 PPP 协议？★

**【面试怎么答】** "PPP 是点对点协议，用于两个结点之间的串行链路，比如早期拨号上网和现在的一些广域网链路。它提供封装成帧、差错检测和链路建立，但只检错不纠错、不保证按序、不提供可靠传输——因为这些交给上层做更合适。

它用特定的标志字节界定帧，遇到数据里出现同样字节时用字节填充或比特填充来转义。"

## 补充 4：网络层（补路由器与过渡技术）

### Q13 转发和路由选择有什么区别？★★

**【面试怎么答】** "路由选择是控制平面的工作，路由器之间运行路由协议交换信息，计算并维护路由表，决定到某个目的网络应该走哪条路，这是一个相对慢的、全局的过程。

转发是数据平面的工作，路由器收到一个分组后查转发表，把它从某个输出端口送出去，这是一个快速的、本地的动作，通常由硬件完成。

对应到路由器结构上，路由器由路由选择部分和分组转发部分组成，前者跑软件算法，后者是交换结构加输入输出端口。"

### Q14 IPv4 向 IPv6 怎么过渡？★★

**【面试怎么答】** "因为不可能一夜之间全网切换，所以需要过渡技术，主要两种。

双栈技术：主机或路由器同时安装 IPv4 和 IPv6 两套协议栈，收到数据报时看首部的版本字段，是 4 就用 IPv4 栈处理，是 6 就用 IPv6 栈处理。这样能同时和两种网络通信，缺点是仍然要消耗 IPv4 地址。

隧道技术：当 IPv6 数据报要穿越一段 IPv4 网络时，在入口路由器把整个 IPv6 数据报作为数据封装进 IPv4 数据报，源和目的地址是隧道两端的 IPv4 地址，穿过去以后在出口路由器拆封还原成 IPv6 继续传输。相当于把 IPv4 网络当成一条隧道用。"

### Q15 为什么 IP 提供的是不可靠服务？★★（有深度，答好加分）

**【面试怎么答】** "这是有意的设计选择，体现的是端到端原则。

理由有几点：一是网络核心保持简单，路由器只需要尽快转发，不用维护每条连接的状态，这样才能支撑巨大的规模和转发速率；二是不同应用对可靠性的需求不同，实时音视频宁可丢包也不要延迟，如果 IP 层强制可靠反而害了它们；三是即使 IP 层做了可靠，端系统为了保证真正的正确性还是得自己再做一遍校验，那 IP 层这层保障就是重复劳动。

所以可靠性被推到了端系统的传输层，需要的用 TCP，不需要的用 UDP，这让网络具备了很强的灵活性和可扩展性。"

### Q16 静态路由和动态路由？★

**【面试怎么答】** "静态路由由管理员手工配置，简单、开销小、可控，但不能自动适应网络变化，适合小型或拓扑稳定的网络。动态路由靠路由协议自动学习和更新，能适应拓扑变化和链路故障，代价是有协议开销和收敛时间，适合大型网络。实际部署中常常混用，比如默认路由用静态配置。"

## 补充 5：传输层与应用层（几个漏掉的点）

### Q17 端口的作用？什么是复用和分用？★★

**【面试怎么答】** "端口是传输层用来标识主机上不同应用进程的 16 位标识符，因为 IP 只能定位到主机，还需要端口才能定位到具体进程。

复用是指发送方多个不同的应用进程都可以通过同一个传输层协议发送数据；分用是指接收方的传输层收到数据后，根据首部里的端口号把数据正确交付给对应的应用进程。

端口分三类：0 到 1023 是熟知端口，分配给标准服务；1024 到 49151 是登记端口；49152 以上是客户端临时使用的短暂端口。"

### Q18 什么是 Socket？★★

**【面试怎么答】** "Socket 是操作系统提供给应用程序访问传输层服务的编程接口，是一层抽象。一个 Socket 由 IP 地址和端口号唯一确定，一条 TCP 连接则由源 IP、源端口、目的 IP、目的端口这个四元组唯一确定。

从系统角度看，Socket 在进程里表现为一个文件描述符，读写连接就像读写文件，这也是 Unix'一切皆文件'思想的体现。TCP 服务端的典型流程是 socket、bind、listen、accept，客户端是 socket、connect，之后双方 read/write，最后 close。"

### Q19 Nagle 算法和延迟确认？★

**【面试怎么答】** "Nagle 算法解决的是小包过多的问题：如果每次只发一个字节，加上 20 字节 TCP 头和 20 字节 IP 头，有效载荷占比极低。它的规则是当有未被确认的数据在途时，新的小数据先攒在缓冲区，等收到确认或者攒够一个 MSS 再发。

延迟确认是接收方收到数据后不立即回 ACK，而是等一小段时间，看能不能捎带在响应数据里一起发出，减少纯 ACK 报文。

两者单独看都合理，但同时开启会互相等待，产生额外延迟。所以对时延敏感的应用，比如游戏或者交互式服务，通常会关掉 Nagle，也就是设置 TCP_NODELAY。这也是我认为很典型的一个例子：单点优化叠加在一起未必是全局最优。"

### Q20 电子邮件的协议？★

**【面试怎么答】** "发送用 SMTP，把邮件从发送方推到发送方邮件服务器、再推到接收方邮件服务器；接收用 POP3 或 IMAP，从服务器拉取邮件。区别是 POP3 通常下载后删除服务器副本，IMAP 保留在服务器上并同步状态，多设备场景下 IMAP 更合适。

另外因为 SMTP 只支持 ASCII，传附件和非英文内容需要 MIME 做编码转换。"

### Q21 FTP 的两个连接？★

**【面试怎么答】** "FTP 使用两条 TCP 连接：控制连接用 21 端口，在整个会话期间一直保持，传输命令和响应；数据连接用于实际传文件，传完就关闭。

数据连接有两种模式，主动模式下服务器用 20 端口主动连回客户端，被动模式下服务器开一个随机端口等客户端来连。现在因为客户端普遍在 NAT 或防火墙后面，服务器连不回去，所以基本都用被动模式。"

## 补充 6：面试节奏的一点提醒

搜实际面经时看到一条挺重要的经验，值得记一下：老师问专业课时**在意的往往不是标准答案，而是你有没有思路、会不会被追问打乱节奏**。遇到不会的题，直接说"我不会"是最差的处理，比较得体的说法是承认这块了解得少、说出自己能推出的部分、并表示会后会去补。这条和主手册附录 C 的三个救场句是一个意思。

另外一个观察：**保研面试的计网题分布比秋招平均**。秋招几乎全是 TCP 和 HTTP，保研老师可能从任何一章随手抽题，尤其是刚给本科生上过课的老师，会问得很教材化（交换方式、复用技术、海明码这种）。所以主手册里我标 ★ 的那些，别完全跳过，至少要能说出一两句。
